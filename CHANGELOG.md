# Changelog

All notable changes to Atlas will be documented in this file.

## [1.0.0] - 2026-08-07

### Added
- Initial implementation of Atlas ML Baseline Engine.
- FastAPI backend with SQLite persistence for experiments and metrics.
- Asynchronous worker process execution using `ProcessPoolExecutor`.
- Scikit-learn and XGBoost pipelines for binary/multiclass classification and regression.
- Deterministic problem type classification logic with human-readable explanations.
- React frontend interface built with Vite and dark theme UI components.
