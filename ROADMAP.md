# Atlas Product Roadmap

## Milestone 1 (Current)
- [x] CSV Dataset upload & schema validation
- [x] Column statistics & preview extraction
- [x] Deterministic problem type detection (Classification vs Regression) with detailed reasoning
- [x] Leak-free data preprocessing engine (train-only fitting for imputers, encoders, and scalers)
- [x] Asynchronous model training via `ProcessPoolExecutor` (Logistic Regression / Ridge, Random Forest, XGBoost)
- [x] Model evaluation metrics & comparison engine
- [x] Dark-themed React user interface (W&B / Grafana aesthetic)

## Milestone 2 (Future)
- Data export & serialized model artifact downloading (.pkl / .onnx)
- Cross-validation support
- Custom hyperparameter tuning
- Extended model suite
